# DENcryptor
DENcryptor is a very simple python GUI program that allows user to create Fernet keys and d/encrypt any message using a valid Fernet key. This tool is free, simple and (of course!) open source. it's not a complex program, but it serves the purpose well. 

FEATURES:

🔑Generate a safe Fernet key using Cryptography.fernet python module

🔒Encrypt any message using a key

🔓Decrypt any encrypted message using a key

NOTES:

-.exe file will not work without the dependencies (ex. icon.ico), you should copy them from the /src folder and move them inside of the same folder as the .exe
